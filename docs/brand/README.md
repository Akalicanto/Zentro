# Identidad de Zentro

La marca utiliza la Z original en forma de cinta violeta y crema, seguida del texto «entro». Al reducir el sidebar solo permanece la Z. Una base crema delimitada mantiene el contraste con los fondos claros y oscuros, sin cambiar los colores originales del símbolo.

El original está en symbol-source.png. La interfaz sirve Zentro.Front/public/brand/symbol-mini.png. El comando node scripts/generate-brand.mjs exporta los iconos transparentes de 32, 180, 192 y 512 píxeles, una variante con fondo crema para el recorte Android y wordmark.png para GitHub. El instalador del acceso directo utiliza el icono de 192 píxeles.
