# Identidad de Zentro

El nombre completo se representa con texto, sin repetir una Z delante. El símbolo es una cartera sencilla con trazos ciruela, fondo lavanda y superficie crema, legible también en modo oscuro.

El original vectorial está en `Zentro.Front/public/brand/symbol.svg`. `node scripts/generate-brand.mjs` genera los iconos PNG de 32, 180, 192 y 512 píxeles para pestaña, Android y otros navegadores. Los iconos de 512 píxeles son compatibles con recorte maskable.
